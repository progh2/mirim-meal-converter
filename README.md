# 급식 식단 변환

월별 식단표 엑셀 또는 나이스 급식 API로, 서울특별시교육청 연구정보원 학교 홈페이지 급식 업로드 양식(**mlsvTmplat**)을 만드는 정적 웹 앱입니다. 어느 학교든 쓸 수 있습니다.

GitHub Pages에서 바로 사용합니다. 엑셀은 브라우저에서만 읽고, 나이스 조회는 [나이스 교육정보 개방 포털](https://open.neis.go.kr/)의 `schoolInfo`·`mealServiceDietInfo`를 호출합니다. 인증키를 넣지 않아도 일반 조회가 됩니다.

## 사용 방법

1. GitHub Pages로 열린 이 앱에서 **식단표 엑셀 올리기** 또는 **나이스에서 가져오기**를 고릅니다.
2. 엑셀을 올리거나, 학교 이름을 검색한 뒤 연월을 선택해 급식을 가져옵니다.
3. 미리보기에서 날짜·끼니·칼로리·메뉴 전체를 확인합니다.
4. **엑셀 다운로드**로 `mlsvTmplat_YYYYMM.xlsx`를 받은 뒤, 연구정보원 학교 홈페이지 급식 서식 업로드에 올립니다.

빌드 단계는 없습니다. `index.html`이 저장소 루트에 있습니다.

## GitHub Pages

Settings → Pages → **Deploy from a branch** → `main` / `/ (root)`.

빌드·Actions가 없어도 루트를 그대로 올리면 됩니다. 이 저장소에는 `.nojekyll`이 포함되어 있습니다.

## 결과 열 의미

| 열 | 이름 | 내용 |
| --- | --- | --- |
| A | 년월일 (YYYYMMDD) | 날짜. 엑셀 날짜이며 표시 형식은 `yyyymmdd` |
| B | 아침:0 점심:1 저녁:2 | 조식=0, 중식=1, 석식=2 |
| C | 제목 | 조식 / 중식 / 석식 |
| D | 식단 | 메뉴를 줄바꿈으로 이음. 알레르기 숫자와 `/` 조합은 유지 |
| E | Kcal | 숫자. 없으면 0 |

헤더 행 높이 32, 글꼴 Arial 10, 열 너비 A14 / B15 / C10 / D62 / E10.

## 변환 규칙

- 엑셀은 달력형 월 식단표(주가 세로로 쌓이고, 요일 칸에 날짜가 있는 표)만 읽습니다.
- 나이스는 해당 연월에 API가 돌려주는 끼니만 넣습니다. 주말·공휴일·빈 석식은 응답에 없으면 빠집니다.
- 나이스 메뉴는 `<br/>`로 나눈 뒤 `(j)`·`(조식)`/`(중식)`/`(석식)`을 빼고, 알레르기 숫자 `(2.13)`는 이름 뒤에 붙여 `단호박타락죽2.13`처럼 만듭니다. 이름 안의 괄호(`셀프토스트바(크로플)`)는 유지하고, 순서는 나이스 그대로입니다.
- 엑셀의 영양 행(`708.6/19.1/245.8/4.5`)은 메뉴에 넣지 않습니다.
- 원산지·알레르기 안내 칸, 옆줄 영양표시제(주간평균)는 무시합니다.
- 이벤트 문구(기후 급식의 날, 슬러시이벤트, 생일이벤트 응모 등)는 그 끼니 메뉴 끝에 붙입니다. 이미 메뉴에 있으면 중복하지 않습니다.
- 어떤 주는 석식 첫 메뉴가 **석식 글자보다 한 줄 위**에 있습니다. 그 줄도 석식에 넣습니다.

## Kcal 계산

Kcal는 열량만 넣습니다. 단백질·칼슘·철분은 더하지 않습니다. 엑셀은 영양 칸의 첫 숫자, 나이스는 CAL_INFO.

- 엑셀 예: `708.6/19.1/245.8/4.5` → **708.6** (첫 숫자=열량)
- 나이스: `CAL_INFO`의 열량만 씁니다. `NTR_INFO`의 단백질·칼슘(칼슔)·철분은 더하지 않습니다.

소수 첫째 자리에서 반올림하고, 정수이면 정수로 둡니다. 값이 없으면 0입니다.

## 테스트

```
npm test
```

나이스 행 → 업로드 양식 매핑과 CAL_INFO Kcal는 고정 픽스처로 검사합니다. 실제 나이스 서버는 CI에서 호출하지 않습니다.

월별 원본 식단표 엑셀이 있으면 기존 달력 파서 검사도 이어서 실행합니다.

```
MEAL_SRC=/path/to/월식단.xlsx node test.js
```

`xlsx`는 `vendor/xlsx.full.min.js`(SheetJS 0.20.3)를 사용합니다.

엑셀 픽스처가 있을 때 확인하는 내용:

- 약 56개 끼니 행
- 2026-09-01 조식 Kcal 708.6
- 9/4 석식 없음, 9/24–25 없음, 주말 행 없음
