# 급식 식단 변환

미림마이스터고 **월별 식단표 엑셀**을 학교 홈페이지 급식 등록용 **mlsvTmplat** 형식으로 바꾸는 정적 웹 앱입니다.

로그인·서버·API가 없습니다. 엑셀은 선생님 컴퓨터 브라우저에서만 읽습니다.

## 사용 방법

1. 이 저장소를 GitHub Pages로 열거나, `index.html`을 브라우저로 엽니다.
2. 영양사 선생님께 받은 그달 식단표(`.xlsx` / `.xls`)를 끌어다 놓습니다.
3. 미리보기에서 날짜·끼니·칼로리를 확인합니다.
4. **엑셀 다운로드**로 `mlsvTmplat_YYYYMM.xlsx`를 받은 뒤, 학교 홈페이지 급식 서식 업로드에 올립니다.

로컬에서 보려면 저장소 루트에서 아무 정적 서버나 쓰면 됩니다.

```
python3 -m http.server 8080
```

빌드 단계는 없습니다. `index.html`이 저장소 루트에 있습니다.

## GitHub Pages

Settings → Pages → **Deploy from a branch** → `main` / `/ (root)`.

빌드·Actions가 없어도 루트를 그대로 올리면 됩니다. 이 저장소에는 `.nojekyll`이 포함되어 있습니다.

## 결과 열 의미

| 열 | 이름 | 내용 |
| --- | --- | --- |
| A | 년월일 (YYYYMMDD) | 날짜. 엑셀 날짜이며 표시 형식은 `yyyymmdd` |
| B | 아침:0 점심:1 저녁:2 | 조식=0, 중식=1, 석식=2 |
| C | 제목 | 조식 / 중식 / 석식 |
| D | 식단 | 메뉴를 줄바꿈으로 이음. 알레르기 숫자와 `/` 조합은 유지 |
| E | Kcal | 숫자. 없으면 0 |

헤더 행 높이 32, 글꼴 Arial 10, 열 너비 A14 / B15 / C10 / D62 / E10.

## 변환 규칙

- 달력형 월 식단표(주가 세로로 쌓이고, 요일 칸에 날짜가 있는 표)만 읽습니다.
- 토·일요일은 제외합니다.
- 실제 메뉴가 없는 끼니(금요일 석식, 추석 등 공휴일)는 제외합니다.
- 영양 행(`708.6/19.1/245.8/4.5`)은 메뉴에 넣지 않습니다.
- 원산지·알레르기 안내 칸, 옆줄 영양표시제(주간평균)는 무시합니다.
- 이벤트 문구(기후 급식의 날, 슬러시이벤트, 생일이벤트 응모 등)는 그 끼니 메뉴 끝에 붙입니다. 이미 메뉴에 있으면 중복하지 않습니다.
- 어떤 주는 석식 첫 메뉴가 **석식 글자보다 한 줄 위**에 있습니다. 그 줄도 석식에 넣습니다.

## Kcal 계산

영양 칸의 숫자를 **모두 더합니다**. 첫 숫자(열량)만 쓰지 않습니다.

예: `708.6/19.1/245.8/4.5` → 708.6 + 19.1 + 245.8 + 4.5 = **978**

소수 첫째 자리에서 반올림하고, 정수이면 정수로 둡니다. 값이 없으면 0입니다.

## 테스트

9월 원본 식단표가 있으면:

```
node test.js
```

환경 변수 `MEAL_SRC`로 원본 경로를 바꿀 수 있습니다. `xlsx`는 `vendor/xlsx.full.min.js`(SheetJS 0.20.3)를 사용합니다.

확인하는 내용:

- 약 56개 끼니 행
- 2026-09-01 조식 Kcal 978
- 9/4 석식 없음, 9/24–25 없음, 주말 행 없음
